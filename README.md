# dlis_investigation
software to investigation of main components of Equinor dlis library.

HUgeeeee thanks to Isabela Dantas de Albuquerque for all support and original investigation.

## Props to fast install and env creation

**1.** Clone this repository to your computer.

**2.** Clone the "C:\Users\mario\Documents\GitHub\dlispy" repository to your computer.

**3.** Certify that you have python installed in the computer (3.12 version is recomendable).

**4.** Create a directory to the proper usage of python environments.

**5.** Correct in the `dlisinv_uff.bat` the paths to your PC.

**6.** Run the `dlisinv_uff.bat` file.
